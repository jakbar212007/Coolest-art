# Make the coolest art — entry

A kohaku (white-and-red) koi leaping toward a full moon over abstract ink
waves, painted in a hand-painted sumi-e style with visible brushwork and
canvas texture, bundled as `art.png`. `main.py` copies it deterministically
to `/output/entry.png` (no network, no randomness — both runs write
identical bytes).
